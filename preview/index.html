How it works

Three steps, every refresh.

The extension never guesses. It reads the same numbers the sites' own usage screens use.

  1. Step 01

    Wake on schedule

    A background alarm wakes the worker every refresh interval — five minutes by default — with no Claude or ChatGPT tab open.

  2. Step 02

    Read the real numbers

    The shared readers parse the usage windows each account endpoint returns, using the sign-in your browser already holds. Meters on the page are the fallback.

  3. Step 03

    Paint the countdown

    The result lands in local storage: toolbar badge, panel cards, seven-day history, and a notification when a limit gets low.

Install

Load it unpacked in under a minute.

No build step, no store account. The files in extension/ are what the browser loads.

  1. 1
    Keep the extension/ folder from this repository on your machine.
  2. 2
    Open your browser's extensions page — chrome://extensions, edge://extensions or opera://extensions — and turn on Developer mode.
  3. 3
    Choose Load unpacked, select the extension/ folder, then pin the icon to the toolbar.

Works in Chrome, Edge, Opera, Brave, Vivaldi and Arc — any Chromium browser with Manifest V3 support (Chrome 102 and newer).

Questions

Answers, in one place.

Everything worth knowing before you install it.

Why does the live panel on this page stay empty?

This page is an ordinary web page, so it can't see your tabs or make requests to claude.ai and chatgpt.com. The installed extension does both from inside your browser — that's the only difference. It ships no sample numbers, so an empty panel here is the same empty panel you get before the extension has read a site.

Do I need to keep a Claude or ChatGPT tab open?

No. A background alarm wakes the worker on your refresh interval and asks both sites for the same numbers their own settings screens show, using the sign-in cookies your browser already holds. Having a tab open just adds a second, page-level reading.

Do I need an account, an API key or a server?

None of them. The extension uses the session you already have in your browser, keeps everything in chrome.storage.local, and sends nothing to any third party. There is no backend to run.

What does the toolbar badge show?

The percentage left on your tightest limit, coloured green, amber or red. In the settings page you can point it at the tightest limit, Claude only, or ChatGPT only, and set the amber threshold with the low-usage alert slider.

How accurate are the numbers?

They come from the same usage windows each site's own settings screen reads, or — when an endpoint doesn't answer — from the meters and limit banners already rendered on the page. Values reflect the last background read or the last tab that reported, so they can lag by up to one refresh interval.

What happens if a site changes its usage screen?

The endpoints are internal and undocumented, so they can change. The page-based fallback keeps the panel useful when they do: the card says read from the page and shows whatever that page displays. extension/readers.js is the single place to update the parsing.

Where is my usage data stored?

In the browser's local extension storage, per provider, alongside a seven-day history of your tightest limit. Clearing the extension's data removes all of it; uninstalling does the same.

Which browsers and permissions does it need?

Any Chromium browser with Manifest V3 — Chrome 102+, Edge, Opera, Brave, Vivaldi, Arc. Permissions: storage for cached numbers, alarms for the background refresh, notifications for low-usage alerts, scripting to inject into Claude or ChatGPT tabs that were already open at install, and host access limited to claude.ai, chatgpt.com and chat.openai.com.

Does it cover API billing or credits?

No. Anthropic Console and OpenAI Platform credit balances require an API key, and this extension deliberately asks for none. It tracks the chat usage limits your signed-in plan exposes.
