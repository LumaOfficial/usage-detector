What it does

  • Claude — your 5-hour session, weekly and extra-credit usage, with reset countdowns.
  • ChatGPT — message limits for your plan and how much of the window is gone.
  • Toolbar badge — the percentage left on your tightest limit, green to red.
  • Seven-day trend — each card draws how far your tightest limit has climbed.
  • Low-usage alerts — a desktop notification when a limit drops below your threshold.
  • Your call — alert threshold, refresh interval, badge focus and panel theme.
  • Zero setup — no account, no API key, no server.

Install it

  1. 1
    Keep the extension/ folder from this repository on your machine.
  2. 2
    Open your browser's extensions page — chrome://extensions, edge://extensions or opera://extensions — and turn on Developer mode.
  3. 3
    Choose Load unpacked, select the extension/ folder, then pin the icon to the toolbar.

Works in Chrome, Edge, Opera, Brave, Vivaldi and Arc — any Chromium browser with Manifest V3 support.

Panel is still empty?

  • Open claude.ai or chatgpt.com in a tab and stay signed in — the extension reads usage from the page you're on.
  • Press the refresh button in the panel. It asks every open tab to report again.
  • Tabs that were already open when you installed the extension are handled for you; a reload of the site always works too.
  • If a site changes its usage screen, the panel says read from the page and shows whatever that page displays.

How it reads usage

A content script runs on claude.ai and chatgpt.com while you're signed in. It asks the site for the same usage numbers its own settings screen shows, and falls back to the meters and limit banners already on the page. Everything is cached in the browser's local extension storage.

  • No account, no API keys, no server — nothing is sent anywhere.
  • Refreshes when you open the panel, when a tab becomes visible, and every five minutes.
